# ShopSphere 2.8 — Final Portfolio Package

This package freezes the 2.8 feature set and adds repository documentation for professional GitHub publication.

## Included

- Multi-retailer electronics comparison
- Product search and filters
- Product details
- Wishlist
- Price history and market movement
- Custom price alerts
- Browser/in-app notifications
- PostgreSQL persistence
- FastAPI backend
- React production build served by Nginx
- Docker Compose setup
- Backend tests and GitHub Actions CI
- README, architecture, security and contribution documentation

## Scope

The project uses demo/reference marketplace data. Exact retailer product-page URLs should be populated from authorized feeds or affiliate/partner data before any production use.
