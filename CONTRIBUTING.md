# Contributing

Thanks for contributing to ShopSphere.

## Development rules

- Keep the Docker-first workflow intact.
- Keep API, database and frontend changes documented.
- Do not commit secrets, `.env` files, `node_modules`, build output or database volumes.
- Add or update tests when changing backend behavior.
- Keep retailer links based on authorized data; do not fabricate exact product URLs.

## Pull requests

Please include:

- What changed
- Why it changed
- How it was tested
- Screenshots for meaningful UI changes
- Any migration or environment-variable changes
